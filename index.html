Tocá el micrófono y hablá con claridad

Cómo dictar para que se entienda bien
  • Producto nuevo (una sola vez): Marca URUS, prenda short, código N115, docenas 18
  • Producto ya cargado: alcanza con Código N115 docenas 18. La app reconoce el código y completa el resto.
  • Código K1515 docenas 16 → 16 docenas del K1515
  • Restar código T1212 unidades 5 → descuenta 5 unidades
  • Conteo código A20 cajas 7 → deja el stock en 7 cajas
  • Decí siempre primero la unidad y después el número: docenas 18, unidades 5, cajas 7.
  • Al detener el micrófono, el formulario se completa solo. Si el código ya existe y está activado el guardado al instante, se guarda sin tocar nada (podés deshacerlo).
